# UTRPRISM v1.0.0

This is the manuscript-associated reproducibility release for UTRPRISM.

It contains:

- the frozen epoch-56 production model and SHA256 checksum;
- reproducible sequence, coverage, feature-construction, and inference code;
- evaluation scripts for development, independent-cohort, human-perturbation, and human-to-mouse transfer analyses;
- the processed state-resolved repression atlas and panel-level reproduction tables;
- selected standalone scientific plotting scripts; and
- pinned environment specifications and file-level provenance.

Raw sequencing files, patient-level clinical metadata, genome-reference bundles, manuscript/submission files, full-figure composition code, deployment configuration, and nonproduction checkpoints are intentionally excluded.

The release was verified with the bundled public-release audit and deterministic inference smoke test. The production-model SHA256 is `a19f915e7cd4ac22c776940d8cf99d12251d7fb78d6c2d57a39f22f9d3b39f65`.
