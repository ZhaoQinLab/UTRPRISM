# UTRPRISM v1.0.2

This release replaces the bundled inference example with the `IL6ST`–`hsa-miR-449c-3p` reference-coverage example used in the Figure 6 gene-query workflow.

The example now includes the human GRCh38 spliced 3′UTR sequence, mature-miRNA sequence, position-matched packaged pooled reference coverage, and the expected prediction retained in the released result table. Model weights, evaluation tables, analysis results, and plotting workflows are unchanged from v1.0.1.
