# UTRPRISM v1.0.4

UTRPRISM v1.0.4 is the archival software release accompanying the Nucleic Acids Research submission.

It includes the frozen epoch-56 production model, inference and preprocessing code, processed reproduction tables, evaluation workflows, standalone plotting scripts, environment specifications, and the verified `IL6ST`–`hsa-miR-449c-3p` reference-coverage example. Scientific contents are unchanged from v1.0.3.
