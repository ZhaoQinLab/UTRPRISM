# UTRPRISM v1.0.1

This release expands the manuscript-associated visualization workflows while preserving the frozen epoch-56 model and released scientific results.

Updates include:

- a simplified top-level `figures/` directory;
- 18 standalone plotting scripts covering development, context-switch, independent-cohort, perturbation, benchmark, and mouse-transfer analyses;
- a shared visual style for newly added plots;
- streamlined repository documentation; and
- a single public-file hash field in the source-data manifest.

All evaluation commands, the deterministic inference smoke test, and every standalone plotting script were run successfully in the release environment.
